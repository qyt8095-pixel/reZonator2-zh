.. _schema_window:

方案窗口
========

这是一个用于操作元件的窗口。方案窗口包含 :doc:`schema_elems` 和方案的 :doc:`layout` 面板。

   .. image:: img/schema_window.png

当方案窗口处于活动状态时，项目窗口的菜单栏中会出现 :menuSelection:`元件` 项。其中包含操作元件的 :ref:`基本命令 <elem_opers>` 。其中一些命令也收录在元件列表和布局的上下文菜单中。
