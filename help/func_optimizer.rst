谐振腔优化
==========

:menuSelection:`函数 --> 谐振腔优化…`

该函数对光路图参数做一键自动优化（类似 Zemax 的局部优化）：在给定变量的取值范围内搜索，使评价函数（Merit）最小。评价函数是各项指标误差的加权平方和，指标包括指定元件处的光斑半径、像散和稳区中心。

该函数仅适用于 :ref:`谐振腔 <trip_type>` ，因为稳区中心的概念不适用于单程系统。

.. note::

  在驻波（SW）谐振腔中，某元件处的光斑半径取**往返起点处**的值，即光束从该元件出发、绕行一周回到该元件时的光斑半径。

变量
----

变量表列出参与优化的参数。每个变量可以是光路图元件的参数，也可以是 :ref:`全局参数 <params_window>` 。

变量分两种模式：

- **连续**：在 [下限, 上限] 区间内连续取值。
- **离散**：只能取候选列表中的值，例如 100, 150, 200, 300, 500。优化时枚举全部离散组合（纯离散组合上限 50000，混合模式上限 2048），每组固定离散值后对其余连续变量做 Nelder-Mead 精修。

只有**自由参数**才能作为变量：由公式或链接驱动的参数不能优化（公式驱动的参数由公式自动计算，链接驱动的参数跟随源参数）。

.. note::

  长度类变量的下限不得小于 1e-6（SI 单位：米）；曲率、焦距类变量的取值区间不得跨过 0（即下限与上限必须同号），因为曲率 0 在物理上无意义。

长度单位
--------

窗口底部的“长度单位”可在 mm 与 µm 之间切换：长度类变量的下限、上限、候选值、当前值与优化值，以及光斑目标值与实测值，都按所选单位显示和输入；其他量纲的参数仍用自身的单位。内部计算和保存的值始终使用 SI 单位，切换单位不改变已保存的数值；所选单位随窗口一起保存在方案文件中。

目标
----

目标表列出评价函数的各项指标：

- **子午光斑 w_T**：指定元件处的子午面光斑半径与目标值的误差。
- **弧矢光斑 w_S**：指定元件处的弧矢面光斑半径与目标值的误差。
- **像散 |wT-wS|**：指定元件处子午与弧矢光斑半径之差，目标为 0。
- **稳区中心 |g|**：稳定性参数 (A+D)/2 的绝对值，目标为 0，即把工作点推到稳区正中。稳区中心目标不需要指定元件，作用于全腔。

每项指标都有权重，默认权重为 1；稳区中心目标的默认权重为 0.1，因为它的量纲（g²）与其他光斑目标（相对误差平方）不同。

评价函数
--------

评价函数是各项指标的加权平方和。光斑目标按相对误差计算：``(w - w_target) / w_target``；像散按 ``|wT-wS| / max(wT, wS)`` 计算；稳区中心按 ``g`` 本身计算。

失稳的腔体不会直接返回常数，而是按失稳程度连续惩罚：``1e4 + 1e5 * (max(0, |gT|-1)² + max(0, |gS|-1)²)``，使求解器能沿着“越来越接近稳定”的方向搜索。

求解器
------

优化使用无导数的 Nelder-Mead 单纯形法（纯 C++ 实现，不依赖第三方库），在 2~6 个变量时效果最好。运行期间除“停止”外的全部控件被禁用；“停止”按钮或关闭窗口都会让当前一轮评估结束后尽快停下。

- **开始**：从当前参数值出发搜索。起点稳定时直接以当前值为单纯形起点（改动最小）；起点失稳时先做粗采样找一个稳定的起点，若全部采样点失稳则跳过该组合。
- **最大迭代次数**：每个连续变量组合的 Nelder-Mead 迭代上限。
- **Merit**：实时显示当前最优的评价函数值。
- **应用结果**：把最优参数写回光路图。
- **还原**：把参数恢复为优化前的值。

.. note::

  稳区中心的最优解不是孤立点：Merit 为 0 的点构成整个 g=0 曲面。并列时优化器选择离初始参数最近的点，即对腔体的改动最小。
