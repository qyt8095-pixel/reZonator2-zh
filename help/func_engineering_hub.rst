工程中心
========

:menuSelection:`函数 --> 工程中心…`

工程中心是二次开发的工程分析入口（Phase 4）：它把 Python 工程包（``engineering/rezeng``）里的重计算——Fox-Li 衍射、热传导与热断裂、鬼像扫描、红光对照、蒙特卡洛公差、ODR 评审报告——以多标签页对话框的形式集成进 reZonator2。C++ 只负责定位后端、启动计算并展示结果，全部物理计算仍在 Python 层。

.. note::

  工程中心需要 Python 工程后端（仓库里的 ``engineering/`` 目录）。对话框按以下顺序查找后端：程序目录旁的 ``engineering/``、环境变量 ``REZONATOR_ENGINEERING_DIR``、设置中的 ``EngineeringHub/engineeringDir``。找不到后端时，各页会显示已查找的位置并禁用运行按钮，不会崩溃也不会静默失败。Python 解释器默认 ``python3``，可在设置中用 ``EngineeringHub/pythonExecutable`` 覆盖。

  另外，后端计算需要一个已保存的方案文件（.she/.rez）：未保存的方案无法运行，须先保存。

标签页
------

- **Fox-Li**：运行 Fox-Li 物理光学衍射引擎，输出收敛情况、往返衍射损耗与各元件处的 D4σ 光斑及 M²。
- **热分析**：运行 2/5/10 W 三档泵浦功率下的热传导与热断裂分析，输出最高温、端面鼓包、最大拉应力与断裂安全裕度（红线：裕度 ≥ 50%）。
- **鬼像**：运行鬼像与标准具扫描，输出一阶鬼像的烧镜点检查与寄生标准具的 FSR、调制深度。
- **红光**：运行 632.8 nm 红光准直对照，输出冷腔与 1064 nm 工作腔在各元件处的光斑与光轴偏移；冷腔失稳时自动切换为外部 HeNe 单程追迹。
- **导出 / ODR**：先导出镀膜表、.zmx 与 .dxf，再汇总光束包络、稳区轨迹、公差良率、热应力裕度与镀膜清单，生成 ODR 评审报告（HTML，可在浏览器中打开或打印为 PDF）。

每个标签页的运行结果先以摘要行呈现，下方附完整的 JSON 原文。计算失败时显示后端退出码与标准错误输出。

.. note::

  各页的参数（泵浦功率、晶体材料、镀膜指标、公差带等）全部来自方案文件旁的工程 side-car（``<方案>.rez.eng.json``）。演示用的 side-car 里的参数是示例值，不是真实激光参数；ODR 报告的页眉会明确标注这一点。

MCP 服务
--------

同一套 Python 引擎还以 MCP 服务端的形式提供（``engineering/mcp_server.py``，stdio 传输），供 Cursor / Claude Desktop 等 AI 客户端调用：``run_foxli``、``analyze_thermal_fracture``、``scan_ghosts``、``redlight_compare``、``export_cad_zmx``、``run_montecarlo``、``generate_odr_report``。详见工程包的 README（“MCP 服务端”一节）。

LIDT 红框预警（主界面元件列表）
----------------------------------

打开方案文件后，若方案旁存在工程 side-car（``<方案>.rez.eng.json``），主界面元件列表会自动跑一次 LIDT 检查：峰值能量密度超过损伤阈值的元件行标浅红底（比值 > 1），接近阈值的标琥珀底（比值 > 0.8）；鼠标悬停在该行上会显示峰值能量密度、阈值与比值。菜单/工具栏的“刷新 LIDT 检查”可手动重跑；光路参数改变后不会自动重跑（避免频繁调用 Python 后端），标记反映的是上一次运行的结果。side-car 缺失或后端找不到时不标记、不报错、不弹窗。

红光模式（一键切换）
--------------------

主窗口工具栏与 :menuSelection:`函数` 菜单中的“红光模式”是一个可勾选的开关：点一下切换到 632.8 nm 红光显示，再点一下切回 1064 nm 工作波长。红光模式复用“元件处光束参数”表：W 列显示各元件处的红光光斑 ``w_633``，新增的 X 列显示光轴偏移 ``x_633``，R/V 列显示 N/A；窗口标题会标明当前是“红光 632.8 nm（外部注入）”还是“红光 632.8 nm（冷腔本征模）”。方案一旦被编辑，红光覆盖即清除（报告只描述已保存的文件）。未保存方案或找不到 Python 后端时，开关置灰并在提示中说明原因。
